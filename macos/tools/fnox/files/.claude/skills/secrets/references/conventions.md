# Secrets: conventions

- The fnox config is `~/.config/fnox/config.toml`. The `fnox` tool of
  bootstrap syncs it, so change it in bootstrap, not on the Mac.
- The config has one provider, `global`: the macOS Keychain, with the service
  `fnox` and the prefix `global/`.
- Each consumer has its own profile, for example `brew` and `fnox`. Give the
  profile and the config to `fnox exec`:
  `fnox -c ~/.config/fnox/config.toml exec -P <profile> -- <command>`.
- The config sets `env = false`, so fnox exports no secret to the shell. A
  secret goes only to the command of `fnox exec`.
- The config sets `if_missing = "error"`, so a missing secret stops the
  command.
- The `brew` alias runs brew through the profile `brew`, which gives
  `HOMEBREW_GITHUB_API_TOKEN` to brew.

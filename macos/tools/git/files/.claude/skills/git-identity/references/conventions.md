# Git identity: conventions

- `~/.config/git/identity` selects `github.config` for a GitHub remote, or for
  a folder below `<projects_dir>/github.com/`. It selects `gitlab.config` for a
  GitLab remote, or for a folder below `<projects_dir>/gitlab.com/`.
- The values come from `[tools.git]` of `macos.toml`: `name`, `email_github`,
  `email_gitlab` and `signing_key`. Use the noreply address of each forge.
- `gpg.format` is `ssh` and `commit.gpgsign` is `true`. `tag.forceSignAnnotated`
  is `true`, so git also signs each annotated tag.
- `~/.config/git/allowed_signers` holds the signing key for each email, so
  `git log --show-signature` can verify a local commit.
- The `git` tool of bootstrap syncs these files. Change them in bootstrap, not
  on the Mac.

# Mac setup: conventions

- `macos.toml` is at `~/.config/bootstrap/macos.toml`. Each
  `[tools.<name>]` table selects a tool of bootstrap and gives its values.
- `bootstrap mac add tool <tool>` and `bootstrap mac remove tool <tool>`
  change the `[tools.<name>]` tables, then sync.
- A package that no tool of bootstrap has goes in the own
  `[mise.bootstrap.packages]` or `[mise.tools]` table of `macos.toml`.
- `mise run updateall:configs` runs `bootstrap mac sync`. With `--dry-run`, it
  shows the changes and writes nothing.
- The sync links the synced files of `$HOME` into `dotfiles/` of this clone.
  bootstrap never commits: examine the changes with git, then commit them.
- Keep the main checkout of this clone on its default branch. `$HOME` links
  into it, so a `git switch` changes the live files of the Mac. Make each
  change in a git worktree with its own branch.

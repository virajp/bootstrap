# User-Level CLAUDE.md

Global conventions for all projects. A project-level CLAUDE.md overrides them.
This file is yours: bootstrap writes it one time only, and never changes it
again. Add your own rules below.

## Stack

- **mise**: `mise` installs the development tools and runs the tasks. Homebrew
  installs the other tools and the apps. List the tasks with `mise tasks`.
- **shell**: some core commands are aliases of other tools. Prefix a command
  with `command` when you parse its output or need its standard flags.

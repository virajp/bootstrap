## Ruling

> - bootstrap layout (user, 2026-11-04): side folders at the root,
>   `repo/tools/<tool>/` and `macos/tools/<tool>/` (not `tools/repo/`), next
>   to `sync-engine/`. The header path becomes `repo/tools/<tool>/<path>` or
>   `macos/tools/<tool>/<path>`.

> - Placement (accepted): `sync-engine/` holds the shared library and both
>   front-ends (repo-sync, setup-sync). `repo/` holds `tools/`, `packs.toml`
>   (out of `tools/`), `examples/` (with `last_sync.toml`). `macos/` holds
>   `tools/`, `packs.toml`, `fixtures/` (today
>   `macos-setup/tests/setup-sync/`). `docs/` stays at the root:
>   `docs/sync/` (no move; plugins name `docs/sync/vwf.md`), `docs/setup/`
>   (Mac guide: sync.md, tool-reference.md), `docs/design/` (both sides).
>   Test tasks: `.config/mise/tasks/test/repo-sync` and `test/setup-sync`.

> - One header on both sides, the repo form with the new path:
>   `Synced from bootstrap: <side>/tools/<tool>/<path>. Do not edit this
>   file` (path per the layout ruling: repo/tools or macos/tools)
>   - `The next sync replaces it, and a manual change is lost`. During the
>     transition the detection (first 3 lines) also accepts `Synced from
>     bootstrap`, `Synced from repo-config` and `Generated by macos-setup`; a
>     later cleanup (with a `migrate.md` step) drops the old texts. Merge
>     sources carry `Merged by bootstrap: <path>` where the format has

## Edits

1. **The move.** Run `mkdir -p repo/tools`, then `mv tools/<tool> repo/tools/`
   for each tool folder, `mv tools/packs.toml repo/packs.toml` and
   `mv examples repo/examples`. Then make
   `tools/repo-sync/.config/mise/tasks/_scripts/`
   again with `mkdir -p`, and move the forwarding file back:
   `mv repo/tools/repo-sync/.config/mise/tasks/_scripts/repo-sync
   tools/repo-sync/.config/mise/tasks/_scripts/repo-sync`.
   Remove `repo/tools/repo-sync/.config/mise/tasks/_scripts/` when it is
   empty. Use plain `mv`: it keeps the file modes. After the move, `tools/`
   holds only the forwarding file (`find tools -type f` prints one line).
2. **The headers.** In each file under `repo/tools/` whose first 3 lines have
   `Synced from bootstrap: tools/`, change that text to
   `Synced from bootstrap: repo/tools/`. Change nothing else on the line.
   Use `sed -i ''` (BSD sed) or a `perl -pi` call on the first 3 lines only.
   Do not change the forwarding file (D5).
3. **Other path text in the moved files.** For each hit of
   `grep -rn 'tools/' repo` that names a source path of bootstrap (for
   example a comment `tools/git/.gitignore`, or `tools/<tool>/tools.toml`),
   write the `repo/tools/` form. A path of the consumer (for example
   `.config/mise/tasks/...`) and a mise word (for example `[tools]`) stay.
   In `repo/examples/last_sync.toml`, the command becomes
   `git log <commit_id>..HEAD -- tools repo docs/sync CLAUDE.md` (D9). Do not
   change
   `commit_id`.
4. **`dprint.jsonc`** — in `excludes`, change the entry `tools/packs.toml`
   (added by P04) to `repo/packs.toml` (D10). Change nothing else.

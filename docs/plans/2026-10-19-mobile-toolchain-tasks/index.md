## Goal

After this plan lands, the `kotlin`, `swift` and `android` tools of bootstrap
ship the generic tasks that the `virajp/claude-plugins` stackgen packs ship
today: the Gradle deps task, the SwiftPM and Xcode deps task, the Android SDK
package install and the Android lint task. The open rulings G1, G7, G8 and K of
the claude-plugins plans are closed in bootstrap, and no mobile tool setup has
to stay in stackgen. This plan finishes backlog item B03.

This is plan 2 of 2 for B03. It requires plan 1,
`docs/plans/2026-10-19-android-swift-java-tools`, which adds the `java`,
`android` and `swift` tools and `docs/sync/vwf.md`. No standing decision is
reversed: the SDK-level and G7 rulings of the user (2026-10-18, 2026-10-19)
are applied as they are.

## Facts the survey established

- After plan 1: `tools/java` defines mise `java` `lts`; `tools/android`
  defines mise `android-sdk` `"23"` (dev, ci, mise `depends = ["java"]`);
  `tools/swift` has no mise tool and the extension `swiftlang.swift-vscode`;
  `tools/flutter` has `depends = ["android"]`; `tools/kotlin` has
  `depends = ["java"]` and only `http:kotlin-lsp` (dev). No tool has a
  Gradle, Swift or Android task yet.
- The `android-sdk` mise tool (`vfox:jdx/vfox-android-sdk`) exports
  `ANDROID_HOME`, `ANDROID_SDK_ROOT` and puts `cmdline-tools/<v>/bin` and
  `platform-tools` on `PATH`.
- `tools/flutter/.config/mise/tasks/setup/deps/flutter` is the model task:
  - `#MISE` and `#USAGE` headers, a `--upgrade` flag;
  - `cd "${MISE_PROJECT_ROOT}"`, then a silent exit 0 when `pubspec.yaml` is
    missing;
  - a normal run is locked (`flutter pub get --enforce-lockfile`,
    `pod install --deployment`);
  - Android: `mise x -- android sdk install platform-tools` when
    `android/gradlew` exists (:64-70), with the comment that a package install
    writes `licenses/`;
  - Gradle in `android/`: `./gradlew dependencies --refresh-dependencies`
    (:82); an outdated report when `ben-manes.versions` is found (:87-98).
    This plan does not change the flutter task.
- Dispatch:
  - `setup` (`tools/base/.config/mise/tasks/setup/_default.tmpl:32-34`) runs
    each executable file in `.config/mise/tasks/setup/deps/` as
    `mise run setup:deps:<name> ${UPGRADE}`. A tool plugs in by shipping
    `setup/deps/<name>`.
  - `code:lint` (`tools/base/.config/mise/tasks/code/lint/_default.tmpl:57-59`)
    runs each `code:lint:<name>` with `${FIX} ${DEBUG} files...`. The
    pre-commit `lint` hook calls `code:lint --fix` with the staged files.
  - Orchestrators find tasks with `own_tasks` from
    `tools/base/.config/mise/tasks/_scripts/helpers:247-264`.
- Task rules (`CLAUDE.md`, "Task scripts" and "Task output"):
  - bash 3.2 and 5.x, no namerefs, no `${var,,}`, no associative arrays;
  - `VAR=$(cmd) || VAR=''` under `set -e`;
  - a task that does not apply prints nothing and exits 0;
  - a leaf prints `print_header` first and once, then `print_subheader` per
    step;
  - tool calls through `mise x --`; host commands (`git`, `awk`, `sed`,
    `swift`, `xcodebuild`, `uname`) without it;
  - each non-seed file starts with the bootstrap header after the shebang:
    `# Synced from bootstrap: tools/<tool>/<path>. Do not edit this file.` and
    `# The next sync replaces it, and a manual change is lost.`;
  - the git mode of a task file is `755`.
- What stackgen ships today (inventory in backlog item B03, read 2026-10-10;
  the pack dirs did not change since):
  - `language/kotlin` `setup/deps/install/kotlin`: skip without `./gradlew`;
    checks `distributionSha256Sum` (64 hex) in
    `gradle/wrapper/gradle-wrapper.properties`; a temporary init script
    registers `stackgenResolveAll` in `allprojects`, which resolves every
    `canBeResolved` configuration; with a `*gradle.lockfile` it runs
    `./gradlew --init-script <tmp> stackgenResolveAll`, else
    `... --write-locks`. `outdated`: `./gradlew dependencyUpdates`.
  - `language/swift` `setup/deps/*/swift`: `swift package resolve
    [--force-resolved-versions]`, `swift package update`.
  - `app-framework/swiftui` `setup/deps/*/swiftui`: exactly one root
    `*.xcodeproj`; `xcodebuild -resolvePackageDependencies -project <p>
    -clonedSourcePackagesDirPath .build/SourcePackages
    [-onlyUsePackageVersionsFromResolvedFile]`; upgrade deletes
    `Package.resolved` and resolves again.
  - `framework/android` `setup/deps/install/android`: ABI `arm64-v8a` on
    arm64/aarch64, else `x86_64`; a bare level of 37 or more becomes
    `<level>.0`; `COMPILE_SDK` matches `^[0-9]+(\.[0-9]+)?$`; packages
    `platform-tools`, `platforms;android-<lvl>`, `emulator`, the image with
    the ABI; licenses with `yes | sdkmanager --licenses`.
  - `framework/android` `code/lint/android`: skip without `./gradlew` or
    `$ANDROID_HOME/platforms`; the file filter
    `*src/*.kt|*src/*.java|*src/*.xml|*.gradle.kts|*.pro|*libs.versions.toml`;
    `--fix` with no files runs `./gradlew lintFix`, else `./gradlew lint`.
- Gap rulings from claude-plugins that land here:
  - G1 (cmdline-tools pin): bootstrap owns the pin as mise tool
    `android-sdk`.
  - G7 (emulator image): "The install task checks `EMULATOR_IMAGE` with
    `sdkmanager --list`. If the id is missing and its `_ps16k` variant
    exists, it installs that and prints which id it used. If neither exists,
    it stops and names both ids." Fact (2026-10-18, `sys-img2-3.xml`):
    `google_apis` exists to `android-37.0`; from `android-37.1` only
    `google_apis_ps16k` exists.
  - G8: "The trigger of `code:lint:android` misses `lint.xml` and
    `lint-baseline.xml`. The lint runs on every module at each commit; it must
    run only on the modules that the commit changed."
  - SDK-level detects (user, 2026-10-19): "each detect also reads
    `build-logic/` and `gradle/libs.versions.toml`, and takes the first hit."
  - K (lock for new modules): "`--frozen` treats the build as locked when any
    `*gradle.lockfile` exists, so a new module resolves unlocked unless the
    build sets `LockMode.STRICT`. … the task must not depend on it alone."
  - No Windows support; macOS and Linux hosts only, and Swift is macOS only.
- Gates: `mise run code` runs dprint (format check), the linter and ShellCheck
  (`code:lint`), and gitleaks, grype and osv-scanner (`code:sec`). No CI, no
  test suite. The sync dry-run of wave-gate line 2 is the plan 1 line with the
  full tool selection.
- Commit convention: types `feat`, `fix`, `perf`, `refactor`, `revert`,
  `test`, `ops`, `docs`, `merge`, `wip`; `commitScopes: []`; the log uses tool
  names as scopes.

## Gates the orchestrator keeps

- **Skip runs** (in U6): in a temporary git repository with no mobile project,
  each new task (`setup:deps:kotlin`, `setup:deps:swift`,
  `setup:deps:android`, `code:lint:android`), run from the run's worktree
  copy with `MISE_PROJECT_ROOT` set to the temporary repository, exits 0 and
  prints nothing.
- **Scratch Kotlin lock check** (in U6): in a temporary folder, make a Gradle
  Kotlin/JVM project with `mise x gradle@latest -- gradle init` (two
  subprojects, Kotlin DSL), add `dependencyLocking { lockAllConfigurations() }`
  to every project and a `distributionSha256Sum` to the wrapper, write and
  commit the locks. Pass: `setup:deps:kotlin` exits 0 and leaves
  `git status --short` empty; after a third subproject with a dependency and
  no lockfile is added and committed, `setup:deps:kotlin` exits non-zero,
  names the new lockfile, and leaves `git status --short` empty.

## Unit contract

Every unit prompt carries, in order: its ruling quoted from this file, its owned
paths plus "touch nothing outside this list", the facts section, the shared-file
rule, and the return block below. A unit never bumps a version, never runs a
generator, never edits a doc outside its Owns, never adds a dependency this file
does not list, never commits. A unit deletes with plain `rm`, never `git rm` —
it stages nothing. A unit never writes a lock file.

A unit returns exactly this block and nothing else — no file contents, no diff:

    CHANGED: <path> — <one line>            (one per file)
    DECIDED: <what> — <why>                 (choices made inside scope, or none)
    DOCS FALSIFIED: <path> — <passage>      (reported, never edited; or none)
    GAP: <what the plan left unspecified and the assumption taken>   (or none)
    UNRESOLVED: <the ruling needed>         (or none)

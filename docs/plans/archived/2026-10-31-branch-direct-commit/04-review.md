# U4 — Review: U1 to U3

## Scope

This review covers U1, U2 and U3, the whole branch delta since the branch
base. U1 and U2 change shell scripts that run — the merge library and
`repo-sync` — which is the reason for this unit (D10). U3 changes only the
examples, and the review covers it so that no unit lands between two reviews
covered by neither.

# Swift conventions

Swift code uses the Swift 6 language mode with strict concurrency. A data race
is a compile error, and the fix is in the design.

**SwiftPM owns the manifest.** `Package.swift` declares the products, the
targets and the dependencies, as ranges (`from:`). `Package.resolved` is the
lockfile, and it is committed, also in a library.

**Errors are thrown.** `precondition` and `fatalError` are for a programmer
error only.

**Tests are Swift Testing** (`@Test`, `#expect`), below `Tests/`.

**The bootstrap tasks own the gates and the dependencies.**
`mise run setup` resolves from `Package.resolved`, and
`mise run setup --upgrade` moves it. `mise run code` runs swift-format and
SwiftLint, each in strict mode.

**A library reads no environment.** The caller gives the configuration as a
value.

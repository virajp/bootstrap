# Kotlin conventions

Kotlin code compiles with warnings as errors. A library also compiles in the
explicit API mode.

**Each tool comes from one place.** The JDK comes from the `java` tool of
bootstrap (Temurin, the LTS line). Gradle comes from the committed wrapper,
and each command is `./gradlew`. The Kotlin compiler comes from the Kotlin
Gradle plugin. The bytecode target is `jvmTarget` with `-Xjdk-release` and
`options.release`, never a Gradle toolchain.

**Null safety stays on.** No `!!`, and a platform type gets an explicit type
at its first use.

**One failure shape for each API**: an own exception hierarchy or a sealed
result. `require` and `check` are for a programmer error only.

**Tests are `kotlin.test` on JUnit 5**, with `runTest` for coroutine code and
Kover for the coverage.

**The bootstrap tasks own the gates and the dependencies.** `mise run code`
runs ktlint and detekt. `mise run setup` checks the lockfiles, and
`mise run setup --upgrade` writes them.

**A library reads no environment.** The caller gives the configuration as a
value, and the library uses only the SLF4J, Micrometer and OpenTelemetry APIs.

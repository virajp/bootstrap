# pnpm conventions

pnpm is the one package manager. The repository has one lockfile,
`pnpm-lock.yaml`, and it is committed.

**The bootstrap tasks install and upgrade.** `mise run setup` installs from
the lockfile and does not move it. `mise run setup --upgrade` moves it.

**A publish cooldown guards the supply chain.** The seed `pnpm-workspace.yaml`
holds `minimumReleaseAge` and the other supply-chain settings. A package that
must run a build script gets an `allowBuilds` entry.

**In a workspace, the internal dependencies are linked**, and a catalog holds
the shared versions.

**An audit is advisory.** The supply-chain gate is `code:sec`.
